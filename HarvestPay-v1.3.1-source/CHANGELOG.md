# Changelog

## 1.4.2 — version code 14

- Native English/Hindi resources across application screens, dialogs, validation, accessibility and notifications.
- Immediate, persistent language selection in More using Android/AppCompat per-app locale APIs.
- Offline expandable English/Hindi version history in About, with a badge based on installed metadata.
- Two-decimal HALF_UP display for GPS/satellite measurement and an editable Bigha input derived directly from full-precision square meters.
- Warning for a positive measurement whose rounded field size is zero; existing save validation prevents zero-sized fields.
- Preserved PDF language independence, historical data, financial calculations and conversion settings.
- Retained R8 optimization, obfuscation and resource shrinking; development signing explicitly authorized by the owner.
